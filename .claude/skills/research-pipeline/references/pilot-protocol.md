# R2a 试做：先用小代价判断分支，再冻结确认协议

试做是探索，不是证据。它回答三类问题：这条路走得通吗（工具能跑、提纲问得出东西、证明思路成立）；阈值、重复次数、样本量大概多少；骨架的哪个分支更可能发生。做完把结论写回潜力卡和骨架分支，再写确认协议。可以免做，但要在协议里写"试点：免做，理由"。

## 规则

- 不碰确认用的材料：最终评测数据、正式样本、正式参与者池、保留的测试对象。试做用过的数据或人，不能再拿来做确认。
- 先写预算和停止条件：多少次运行、多少个对象、多少位受访者、多少天；到了就停。
- 产出标 exploratory，不进论文证据；要进论文必须在确认协议下重做。
- 只用来做决定：定阈值与最小有意义差异、定重复次数或样本量、定走哪个分支、定工具或提纲的可行性。
- 试做看到的任何"有趣结果"不是结论，是确认协议里的一条假设。

## 文件

```markdown
# PILOT_<YYYYMMDD>_<短名>（exploratory）
- 研究类型：

## 目的
- 要决定的事（阈值 / 重复次数或样本量 / 分支 / 可行性）

## 范围与预算
- 用了哪些材料；明确没碰哪些；预算与停止条件

## 结果（exploratory，不进论文证据）
- 对每个要决定的事给出决定与依据；写回潜力卡与骨架的哪一处

## 授权
- 引用用户的具体授权
```
