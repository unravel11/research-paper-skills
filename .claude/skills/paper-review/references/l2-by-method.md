# L2 按研究类型怎么审

L2 的十道门对所有研究通用，问的是同一件事：从对象到结论这条证据链有没有断点。每种研究类型断点长得不一样，所以每门在不同类型里要问的具体问题不同。先确定研究类型，再按对应小节审；门的编号、状态值和处置表不变。

**研究类型从哪来。** 优先读 `experiments/PROTOCOL_*.md` 第一行的 `- 研究类型：`；没有协议就读 `paper/FRAMING.md` 开头的 `- 研究类型：`（R1 选定，R2 协议继承）；都没有就问用户。类型名以 `research-pipeline/references/methods/` 的档案名为准（quantitative-experiment、measurement-study、tool-or-system-evaluation、case-study-or-qualitative、human-subjects-experiment、formal-or-theoretical、replication），一篇论文用到两种就两节都审。没有声明且问不到时，按通用问法审，并在报告里写"研究类型未声明"，L2-G0 至多 `PARTIAL`。

**记录。** `REVIEW-RECORD.json` 的 `target.research_type` 写档案名；每门的"直接证据"栏引用本节问题对应的材料。

## 通用十门

| Gate | 核心问题 |
|---|---|
| L2-G0 协议冻结与偏离 | 协议或分析计划在接触确认性结果之前冻结；偏离登记了日期、理由、谁决定、影响；为找结果而改的地方是否披露并与确认性结果分开 |
| L2-G1 对象、样本与分母 | 研究对象或数据从哪来、怎么选、分母是什么；排除、缺失、失败、未决案例能否重建；便利样本不支撑总体结论 |
| L2-G2 真值、度量与标注 | 结论依赖的"真"从哪来，是否独立于被评的对象；度量测的是不是要测的东西；标注过程、标注者独立性、分歧与信度可见 |
| L2-G3 隔离与泄漏 | 探索与确认是否隔离；做决定前分析者看过什么；结果信息有没有泄回对象选择、配置或假设 |
| L2-G4 分析单位与配对 | 在哪一层比较、在哪一层重复；重复是不是独立的（伪重复）；同池比较与端到端比较分开 |
| L2-G5 过程受控 | 影响结果的过程（调参、编码本版本、访谈者行为、工具配置、证明假设的变更）是否受控并有记录 |
| L2-G6 对照、替代方案与消融 | 对照或替代方案公平且不是稻草人；竞争解释被排除；消融或反例与所声称的机制对应 |
| L2-G7 判定、统计与不确定性 | 判定按协议规则得出；区间与变异而不只是点估计；多重比较；定性的饱和与信度；没有设计支撑不用因果或总体语言 |
| L2-G8 稳健性与外部效度 | 敏感性、失败案例、配置或情境边界是否报告；结论限定在观察到的范围 |
| L2-G9 复现链、材料与披露 | 关键数字可从材料重建；脚本、材料、版本有指纹；数据与材料的可得性和限制写明；伦理、披露与科学结论分开 |

## quantitative-experiment：受控实验与基准评测

| Gate | 这类研究里具体审什么 |
|---|---|
| L2-G0 | 判定规则、阈值、重复次数在看评测结果前写定；看结果后改的配置登记为偏离 |
| L2-G1 | 数据或基准的版本与来源；预处理与过滤；每格有多少对象；失败运行怎么计 |
| L2-G2 | 标签或参照的来源与质量；被评方法不能给自己打分；自动裁决有抽样复核 |
| L2-G3 | 训练、调参、开发、最终评测的数据隔离；候选选择或提示迭代有没有碰评测集；实体、时间、派生样本隔离 |
| L2-G4 | 配对还是独立比较；在种子、样本还是数据集层重复；伪重复 |
| L2-G5 | 超参选择、种子、checkpoint、早停的记录；对评测结果的反馈受控 |
| L2-G6 | 基线是当前最强版本且调参预算相同；消融隔离所声称的组件 |
| L2-G7 | 区间与多重比较；一致性规则；指标方向与分母；单次运行不写成稳定 |
| L2-G8 | 换种子、换数据集、换配置后结论是否变；失败案例与版本边界 |
| L2-G9 | 脚本、配置、环境的指纹；数字可从输出文件重建 |

## measurement-study：测量研究与实证规律

| Gate | 这类研究里具体审什么 |
|---|---|
| L2-G0 | 筛选条件、度量定义、时间窗在看结果前写定；事后调整的筛选登记 |
| L2-G1 | 抽样框与总体；每步筛选的分母表；筛选条件的人工验证；样本量 |
| L2-G2 | 度量是否已验证或做了构念效度评估；人工标注的编码本、人数、信度 |
| L2-G3 | 探索性挖掘与确认性分析分开；规律是不是在同一批数据上先看到再"验证" |
| L2-G4 | 观察单位与分析单位（提交、文件、项目、作者）；聚合层级；重复计数 |
| L2-G5 | 抓取与清洗脚本版本；API 限制与缺失处理记录 |
| L2-G6 | 竞争解释（时间趋势、规模效应、选择偏差）是否排除；对照组或基准期 |
| L2-G7 | 区间或分布；效应大小的最小有意义值；主张类型（描述、关联、因果）与证据匹配 |
| L2-G8 | 换阈值、换时间窗、换数据源的敏感性；外部效度限定在抽到的总体 |
| L2-G9 | 数据快照与脚本的指纹；样本清单可得 |

## tool-or-system-evaluation：工具、系统或方法的工程评估

| Gate | 这类研究里具体审什么 |
|---|---|
| L2-G0 | 对象集、口径、失败处理规则在跑之前写定；事后排除的对象登记 |
| L2-G1 | 对象集怎么选、是否代表目标场景；对象数与特征；超时与崩溃计入分母 |
| L2-G2 | 正确性的真值从哪来；裁决规则与复核；工具不能自证 |
| L2-G3 | 开发时用过的对象与评估对象是否隔离；调试时看过的失败案例 |
| L2-G4 | 每对象一次还是多次运行；性能类的重复与预热；同环境比较 |
| L2-G5 | 工具版本、配置、环境固定；替代方案的配置与预算公平 |
| L2-G6 | 替代方案是最强现有工具且正确运行；消融对应组件主张 |
| L2-G7 | "优于"的标准事先定；区间；平局与失败的处理 |
| L2-G8 | 不同对象子集上的表现；失败案例分析；受控对象集不等于真实部署 |
| L2-G9 | artifact 版本、对象集清单、运行脚本、裁决记录的指纹 |

## case-study-or-qualitative：案例、访谈、问卷

| Gate | 这类研究里具体审什么 |
|---|---|
| L2-G0 | 提纲、编码本、预期主题在访谈或发放前写定；编码本的修订有版本与日期 |
| L2-G1 | 案例或受访者的选择理由；描述维度；拒绝与脱落人数；问卷的回应率与无回应处理 |
| L2-G2 | 构念怎么操作化；量表是否已验证；编码者人数、独立性、分歧解决、信度 |
| L2-G3 | 研究者立场与偏向；分析过程中新假设是否回头影响了后续访谈的提问 |
| L2-G4 | 分析单位（人、团队、组织、事件）；引语计数的单位；同一人的多条引语不算多个来源 |
| L2-G5 | 访谈者行为一致；提纲变更记录；问卷发放与监控过程 |
| L2-G6 | 反例与负面案例分析；三角验证；竞争解释 |
| L2-G7 | 主题成立的标准；饱和的证据；信度统计与下限；定性结果不做无依据的数量化 |
| L2-G8 | 不同案例或人群间是否一致；结论限定在研究过的情境 |
| L2-G9 | 提纲、问卷、编码本可得；匿名化与伦理审批；证据链表 |

## human-subjects-experiment：以人为参与者的实验

| Gate | 这类研究里具体审什么 |
|---|---|
| L2-G0 | 假设、主要结果、分析计划在收集数据前预注册或冻结；偏离列表 |
| L2-G1 | 招募来源与纳入排除；参与者流程（招募、排除、脱落、分析）；样本量理由 |
| L2-G2 | 因变量的测量方式与效度；操作检查；评分者独立 |
| L2-G3 | 参与者或实验者是否知道条件；试点参与者是否进入正式样本 |
| L2-G4 | 组间还是组内；随机分配单位；重复测量的处理 |
| L2-G5 | 随机化方法与逻辑；任务与材料固定；实验者行为一致 |
| L2-G6 | 对照条件合理；顺序与学习效应被平衡；竞争解释排除 |
| L2-G7 | 按计划的检验；效应量与区间；多重比较；不显著不写成无效应，报最小可检测效应 |
| L2-G8 | 去掉未通过注意力检查者后结论是否变；外部效度限定在参与者群体与任务 |
| L2-G9 | 材料、指导语、分析脚本可得；伦理审批编号 |

## formal-or-theoretical：形式化与理论

| Gate | 这类研究里具体审什么 |
|---|---|
| L2-G0 | 假设清单与证明义务在动手前写定；证明中加强假设要登记 |
| L2-G1 | 主张的适用范围与对象类（哪些系统、哪些输入）；边界情形 |
| L2-G2 | 定义精确且与文献一致；非形式化主张与形式化主张分开 |
| L2-G3 | 定义是否为了让定理成立而事后调整；反例搜索的范围 |
| L2-G4 | 每条主张对应的引理与依赖；循环依赖 |
| L2-G5 | 机械化工具版本；可信基础（公理、外部库）；纸笔与机械化的边界 |
| L2-G6 | 与已有结果的关系（推广、特例、矛盾）；替代形式化 |
| L2-G7 | 证明状态表（已证、依赖假设、未证、反例）；每条假设的必要性 |
| L2-G8 | 退化情形与极端参数；假设去掉后主张是否仍成立 |
| L2-G9 | 定义文件与证明脚本可得；机械化检查可重跑 |

## replication：复现与再现

| Gate | 这类研究里具体审什么 |
|---|---|
| L2-G0 | 一致性标准与差异清单在跑之前写定；偏离原设计的地方登记 |
| L2-G1 | 对象或参与者与原研究的异同；样本量与原研究可比 |
| L2-G2 | 用原材料还是重建；重建的材料与原文一致性检查 |
| L2-G3 | 本研究是否先看过原结果再调整流程；再现性检查（原数据上得到原数字） |
| L2-G4 | 比较单位与原研究一致 |
| L2-G5 | 原作者材料的版本；本研究脚本的版本 |
| L2-G6 | 不一致结果的竞争解释（材料差异、情境差异、原结果本身） |
| L2-G7 | 一致与不一致分开报告；一致性标准按事先定的算 |
| L2-G8 | 差异对结论的影响逐项评估 |
| L2-G9 | 原材料与本研究材料清单；差异登记可得 |
