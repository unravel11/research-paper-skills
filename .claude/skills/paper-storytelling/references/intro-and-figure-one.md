# 引言、图一与回答框的写法

## 引言的六步

1. **读者处境**（1 段）：读者今天面对的具体任务和规模。用一个真实、脱敏的例子开场比定义更有力。
2. **原做法与为什么合理**（1 段）：公平地说明现有做法的道理，引用出处。读者要认得出自己。
3. **张力**（1 段）：把例子推到现有做法付出代价或失败的地方。数字只用一两个，且是读者关心的量（成本、错误、人工）。
4. **转折**（1 段）：本文的关键发现，用读者语言说，不用方法代号。此处可引图一。
5. **收获与边界**（1 段）：读者能据此改变什么决定；明确不主张什么。
6. **贡献列表**（≤4 条）：第一条是转折；负结果与消融不单列为贡献，可作为第 3/4 条的从句。

每段第一句是该段的结论。引言总长不超过全文的 10%。

## 图一

- 目标：读者只看图一和图题就能复述转折。
- 优先形式：一张权衡图（例如成本 vs 质量，标出"现做法"、"本文"、"不可及的理想点"），或一个对照示例（左：现做法失败；右：本文的做法）。
- 禁止：系统框图作为图一（框图放方法节）；需要读正文才能看懂的图。
- 图题：第一句是结论句，随后一两句说明读法；不在图题里堆数值。
- 风格：字号接近正文；同一方法全文同色；直接标注优于图例；不用 `resizebox` 把整图缩小。

## Answer-to-RQ 框

每个 RQ 结尾放一个框（`tcolorbox` 或简单的 `\fbox`/缩进段）：

```
Answer to RQ1. <一句结论，含最关键的一个数字>。<一句回扣：这意味着骨架中的哪一环成立 / 在什么边界内>。
```

框里不出现判定规则编号、运行编号、协议名。

## 数字的用法

- 正文每句最多两个数字；区间放表格或森林图。
- 保留小数位按样本量定：2,000 条样本里一条只值 0.05 点，保留一位小数即可。
- 同一个量全文只用一种说法（"约一半"和"48.3%"二选一，并在首次出现时对应）。

## 结论

重述一句话故事 → 收获 → 边界 → 一个明确的开放问题。不重复结果数字。
