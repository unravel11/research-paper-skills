# 异常入口：从一个解释不了的观察起步

研究常常不是从主题开始，而是从一个解释不了的观察开始。它在不同类型的研究里长得不一样：整体指标在涨而某个子群在跌；某类对象在数据里的比例和大家以为的差一个数量级；工具在某种输入上稳定失败而文档说支持；几位受访者不约而同说出一个与文献相反的做法；参与者的行为与任务说明的预期相反；一个"显然成立"的引理在一个小例子上不成立；按原文设置复现，结果方向相反。这类观察大多数最后是错误或伪像，少数是现象。这个入口的任务是用尽量小的代价把两者分开，再把现象变成可以进 R1 的方向。顺序不能反：先排伪像，再谈重要性；先刻画现象，再查文献；先有潜力卡，再谈方法。

阶段锁照旧：这里的检查是诊断，不是实验设计。只用已有的材料、配置和脚本（数据、记录、代码、证明草稿都算），不引入新方法，不选基线或对照，不定论文指标；预算和停止规则写明；所有产出标 exploratory，不进论文证据。检查由用户或项目自己的脚本和人手执行，本 skill 只列检查、读回执、填表。

## A. 写观察句

一句没有解释的话：在什么对象、材料、条件和度量上，看到了什么，和预期差多少，预期从哪来（文献、默认设置、常识、原文），第一次看到是什么时候，原始记录在哪（输出文件、日志、访谈记录、计算或证明草稿）。不写"因为"。原始记录原样保留，不覆盖；以后每一次重做都是新文件。同时写下这个异常是怎么被挑出来的：看过多少次运行、多少个子群、多少份记录、多少个例子。看得越多，它越可能只是选择效应。

## B. 排伪像

先列最可能的伪像来源，每条写一个与假设无关的检查，以及"什么结果能排除它"。来源对所有研究类型通用，典型伪像按类型举例：

| 来源 | 典型伪像 | 便宜的检查 |
|---|---|---|
| 材料与对象 | 对象重复或两组重叠、来源混入、标注或转录错误、两组的处理步骤不一致、对象随时间漂移 | 去重与重叠统计；抽样人工核对标注或转录；逐项对比两组的处理步骤 |
| 分母 | 子群太小，一两个对象就能让数字摆动；一个说法只来自一两个人、一两处 | 报告每个子群的 n 与区间；按 n 过滤后再看趋势；定性写清几个人、几处说过 |
| 配置与版本 | 实际用的和以为用的不一样：参数没更新、工具或库的版本不同、编码本或问卷的版本不同、定义中途变过 | 对比实际加载的配置或版本与记录；两个结果完全一致先怀疑没更新 |
| 度量与口径 | 度量定义与直觉不一致、聚合方式掩盖子群、脚本或编码规则的口径变过、单位或时区混用 | 用第二种实现或第二位编码者重算一次；分子分母逐项核对 |
| 执行过程 | 中断后从错误状态恢复、环境不同、访谈者引导了回答、参与者理解错任务、证明里用了没声明的假设 | 查执行记录与重启记录；固定环境重做一次；读原始记录而不是摘要 |
| 选择 | 看过很多次运行、子群、记录或例子后挑出来的那个"异常" | 写下看过多少、怎么挑的；这决定它只能叫探索性观察 |

每条检查做完填结果：排除 / 未排除 / 未查。全部填完之前不下结论。留下"未排除"的，进 R1 时写进前提条件，不假装不存在。给这一步一个预算，到了就停下向用户汇报；排伪像花掉几周是常态，不是失败。

## C. 复现与刻画

伪像排除后，用最小代价回答三个问题：再做一次还在吗（换一次重复、换一位编码者、换一批样本）；换一个对象、材料、条件或设置还在吗；什么条件下出现、什么条件下消失。结果写成一张现象卡：条件、幅度、稳定性、边界。幅度带区间与 n，定性带几人几处；只做过一次只能叫单次观察。这一步仍然不设计方法，也不解释机制。

## D. 现象变问题

- 这个现象反驳或限定了读者现有的哪个信念？信念的来源是什么：文献、工业实践、常用默认设置。
- 如果它成立，谁会改变什么判断；如果它最终被某个解释说明了，那个解释本身是否仍有人在乎。
- 文献对照：以现象为检索词，用本 skill 第 2 步的压缩格式读最接近的几篇；结论只有三种：已被报告（在什么条件下）、部分报告、未见报告（标待核实）。已被完整报告不等于没有方向，剩下的可能是边界或解释。

## E. 潜力卡

和主题入口同一张四问卡：重要在哪、谁在乎；合理的进攻路线（手里已有可复现的现象，这是异常入口天然的优势）；最脆弱的假设与最小判别证据（通常是"还有没想到的伪像"和"换最强的替代解释、更大的样本或更严的条件后还在不在"，这两条就是 R2 试点要做的）；答案反过来是否仍有人在乎。写进 innovation-log 的"最终选定"，和文献迁移来的方向一起排序。

## 退出

同主题入口。多一条：排伪像表和现象卡随方向进入 R1，`paper-framing` 的"恢复证据与选择历史"直接引用它们，不重做；现象卡里的条件和边界就是 R1 骨架里张力与分支的素材。
