# 学术写作偏好

仅在学术正文写作、改写或润色时读取。以下是默认语气；项目自己的 AGENTS.md / CLAUDE.md 里更具体的证据与写作要求优先。

## 学术论文写作默认语气

- 采用“证据校准的明确表达”，不采用防御式写作：表述强度必须与证据强度匹配，而不是一律写弱。
- 对材料直接报告的观察、数值、比较和已执行动作直接陈述；对解释性推断只保留一个准确的认识性限定；未验证假设明确标为假设、可能性或未来工作。
- 删除同义 hedge 叠加、重复局限、作者心理和预防审稿式免责声明；适用范围在首次影响结论处说明，系统性局限集中到 Threats to Validity 或 Limitations。
- 去除防御式外壳不得加强科学主张；不得把相关性改成因果、局部结果改成普遍结论、实验支持改成证明，或突破项目自己的 claim ceiling。项目级 `AGENTS.md` 中更具体的证据与写作规则优先。
